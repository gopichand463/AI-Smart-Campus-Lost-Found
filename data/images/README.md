# Lost & Found Image Dataset Directory

Place your extracted Roboflow dataset files here.

### Expected Structure:
```text
data/images/
├── train/
│   ├── images/
│   └── labels/
├── valid/
│   ├── images/
│   └── labels/
└── test/
    ├── images/
    └── labels/
```
Or simply put all `.jpg`/`.png` photos directly inside this folder if downloading as a raw image folder.
